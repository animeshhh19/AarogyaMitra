Objective for the Week

The objective of Week 2 was to move from proposal to practice: set up the Next.js frontend locally, install and configure Shadcn, and start building the core patient and doctor portal pages.

Day 1 — Frontend Environment Setup

Set up the Next.js frontend locally from the forked repository, for example configuring environment variables for the API base URL and Firebase config.

Installed and configured the Shadcn component library and set up the base theme and layout used across both portals.

Day 2 — Authentication Pages

Built the registration and login pages for patients and doctors, wiring them up to the Firebase Authentication flow the backend teammate set up.

Added basic form validation, for example checking required fields and password rules before submitting.

Day 3 — Patient Profile and Doctor Discovery

Built the patient profile page for viewing and editing personal details.

Built the doctor discovery page, for example listing available doctors with basic filtering, so a patient can find a doctor before booking.

Day 4 — Doctor Dashboard Base

Built the base layout for the doctor dashboard, including navigation between availability, appointment queue, and consultation history sections.

Implemented the availability management screen, letting a doctor toggle available time slots.

Day 5 — Appointment Booking UI

Started building the appointment booking flow on the patient side, for example selecting a doctor, choosing an available slot, and confirming the booking.

Connected the booking UI to the backend's appointment endpoints and handled basic error states, for example a slot becoming unavailable before confirmation.

Day 6 — Integration Check-in and Planning

Did a joint test with the team, registering and logging in as both a patient and a doctor through the actual UI and confirming the flow matched the backend responses.

Reviewed progress against the initial deliverable checklist from the proposal and flagged the appointment queue view and consultation UI as priorities for next week.

Planned next week's work: finish the appointment booking flow end to end and start building the consultation chat screen.

Week 2 Deliverables

Next.js frontend running locally with Shadcn configured.

Working registration and login pages for patients and doctors.

Patient profile and doctor discovery pages.

Doctor dashboard base layout with availability management.

Appointment booking flow in progress on the patient side.
